# 4节点 DeepSeek-V4-Pro 性能测试（TP=8 PP=4，有 HiCache，mem=0.95，swa=0.2，chunked-prefill-size=4096，EAGLE 投机解码）

## 配置信息

- mem-fraction-static: 0.95
- max-running-requests: 64
- swa-full-tokens-ratio: 0.2
- chunked-prefill-size: 4096
- disable-cuda-graph: 是
- disable-overlap-schedule: 是
- 代码修复: hybrid_pool_assembler.py start_layer 偏移修复
- EAGLE 投机解码: 是（均衡模式）
  - speculative-algorithm: EAGLE
  - speculative-num-steps: 1
  - speculative-eagle-topk: 1
  - speculative-num-draft-tokens: 2
  - 注: DSV4 使用内置 MTP 头，无需指定 --speculative-draft-model-path（自动设为目标模型路径）

## 脚本

### dist-init-addr地址
172.16.107.21

### 启动命令

**Node 0 (rank=0)** — 进入 Pod 0 后执行：

```bash
kubectl exec -n elm-test -it dsv4pro-sg-gx-0 -- bash
```

```bash
SGLANG_SHARED_EXPERT_TP1=1 \
SGLANG_ENABLE_UNIFIED_RADIX_TREE=1 \
python3 -m sglang.launch_server \
--model-path /userdata/dsv4/DeepSeek-V4-Pro \
--served-model-name deepseek-v4-pro \
--trust-remote-code \
--tp 8 \
--pp-size 4 \
--moe-runner-backend marlin \
--nnodes 4 \
--node-rank 0 \
--dist-init-addr 172.16.107.21:20000 \
--context-length 1048576 \
--mem-fraction-static 0.95 \
--disable-cuda-graph \
--disable-overlap-schedule \
--watchdog-timeout 3600 \
--enable-hierarchical-cache \
--hicache-ratio 2.0 \
--hicache-write-policy write_through \
--hicache-io-backend direct \
--max-running-requests 64 \
--swa-full-tokens-ratio 0.2 \
--chunked-prefill-size 4096 \
--speculative-algorithm EAGLE \
--speculative-num-steps 1 \
--speculative-eagle-topk 1 \
--speculative-num-draft-tokens 2 \
--host 0.0.0.0 \
--port 8080
```

## 关键对比分析

### 1. C60 稳定性：swa=0.2 根本性解决 OOM 问题

| 配置 | C60 R1 | C60 R2 | C60 R3 |
|------|--------|--------|--------|
| swa=0.1 | 28706 tok/s | **OOM 崩溃** | **OOM 崩溃** |
| swa=0.2 | 12291 tok/s | 13151 tok/s | 12830 tok/s |

**这是最核心的改进。** swa=0.1 下 C60 仅 R1 勉强运行（靠前序测试预热 HiCache 腾出空间），R2 即 OOM。swa=0.2 下 C60 三轮全部稳定运行，且 R2/R3 性能反而优于 R1（Input 13151 vs 12291 tok/s），说明没有内存压力累积问题。

原因：swa=0.2 将更多 token 从 full KV cache 迁移到 SWA（滑动窗口注意力），full KV cache 占用减少约一半，为 prefill 阶段腾出大量 GPU 内存空间，避免 OOM。

### 2. C10 吞吐：swa=0.2 明显低于 swa=0.1

| 指标 | C10 R1 | C10 R2 | C10 R3 |
|------|--------|--------|--------|
| swa=0.1 Input (tok/s) | 6107 | 6482 | 7726 |
| swa=0.2 Input (tok/s) | 6095 | 6145 | 6107 |
| 差异 | -0.2% | -5.2% | **-21.0%** |

| 指标 | C10 R1 | C10 R2 | C10 R3 |
|------|--------|--------|--------|
| swa=0.1 Mean TTFT (ms) | 2019 | 1815 | 1096 |
| swa=0.2 Mean TTFT (ms) | 2132 | 1929 | 1983 |
| 差异 | +5.6% | +6.3% | **+81.1%** |

C10 低并发下 swa=0.2 吞吐显著低于 swa=0.1，尤其 R3 差距达 21%。swa=0.1 的 R3 有明显的 HiCache 预热加速效应（6107→7726，+26%），而 swa=0.2 的三轮几乎无提升（6095→6107，+0.2%）。

原因分析：
- swa=0.2 导致 SWA token 比例更高，decode 阶段需要重新计算被丢弃的 KV，增加了计算开销
- 低并发时 GPU 内存本身不紧张，swa=0.1 的 full KV cache 不构成内存压力，反而因为无需重算 KV 而有更好的 decode 性能
- HiCache 预热效应在 swa=0.2 下减弱，因为更多 token 使用 SWA 而非 HiCache offload

### 3. C30 吞吐：swa=0.2 显著低于 swa=0.1

| 指标 | C30 R1 | C30 R2 | C30 R3 |
|------|--------|--------|--------|
| swa=0.1 Input (tok/s) | 11932 | 15289 | 22351 |
| swa=0.2 Input (tok/s) | 10316 | 10815 | 10683 |
| 差异 | **-13.5%** | **-29.3%** | **-52.2%** |

| 指标 | C30 R1 | C30 R2 | C30 R3 |
|------|--------|--------|--------|
| swa=0.1 Mean TTFT (ms) | 7057 | 6797 | 3139 |
| swa=0.2 Mean TTFT (ms) | 4830 | 4792 | 4744 |
| 差异 | -31.6% | -29.5% | +51.3% |

C30 是差异最显著的场景。swa=0.1 的 R3 达到惊人的 22351 tok/s（Input），而 swa=0.2 仅有 10683 tok/s。

但注意一个重要细节：**swa=0.2 的 TTFT 在 R1/R2 明显优于 swa=0.1**（4830 vs 7057 ms，低 31.6%），但 R3 反转（4744 vs 3139 ms，高 51.3%）。这再次说明 swa=0.1 在预热后 decode 阶段更高效，而 swa=0.2 在冷启动时 prefill 更快（因为 full KV cache 占用更少，prefill 内存更充裕）。

### 4. C60 吞吐：swa=0.2 稳定但吞吐较低

| 指标 | C60 R1 | C60 R2 | C60 R3 |
|------|--------|--------|--------|
| swa=0.1 Input (tok/s) | 28706 | OOM | OOM |
| swa=0.2 Input (tok/s) | 12291 | 13151 | 12830 |
| 差异 | **-57.2%** | — | — |

| 指标 | C60 R1 | C60 R2 | C60 R3 |
|------|--------|--------|--------|
| swa=0.1 Mean TTFT (ms) | 13638 | OOM | OOM |
| swa=0.2 Mean TTFT (ms) | 26783 | 21578 | 22533 |

swa=0.2 的 C60 吞吐仅为 swa=0.1 R1 的 43%，TTFT 几乎翻倍。但 swa=0.1 的 R1 数据本身不可靠（因为后续即 OOM，说明已处于内存极限边缘），而 swa=0.2 的三轮数据一致且稳定。

### 5. TPOT 对比：swa=0.2 在高并发下 decode 更慢

| 并发 | swa=0.1 TPOT (ms) | swa=0.2 TPOT (ms) | 差异 |
|------|--------------------|--------------------|------|
| C10 R3 | 230.7 | 291.7 | +26.4% |
| C30 R3 | 426.2 | 499.7 | +17.2% |
| C60 R1 | 471.0 | 606.6 | +28.8% |

swa=0.2 在所有并发级别下 TPOT 均高于 swa=0.1，说明 SWA 机制引入的 KV 重计算开销是持续性的。

### 6. HiCache 预热效应对比

**swa=0.1 预热效应：**
- C10 R1→R3: Input +26%, TTFT -46%
- C30 R1→R3: Input +87%, TTFT -55%

**swa=0.2 预热效应：**
- C10 R1→R3: Input +0.2%, TTFT -7.0%
- C30 R1→R3: Input +3.6%, TTFT +1.8%

swa=0.2 几乎消除了 HiCache 预热效应。三轮测试间性能几乎没有变化，说明 swa=0.2 下的性能瓶颈不再是 HiCache offload 速度，而是 SWA 重计算的固定开销。

### 7. 延迟稳定性：swa=0.2 三轮间更稳定

swa=0.2 的 C10/C30 三轮间 Input throughput 方差极小（C10: 6095-6145，波动 <1%；C30: 10316-10815，波动 <5%），而 swa=0.1 波动巨大（C10: 6107-7726，波动 26%；C30: 11932-22351，波动 87%）。

这对生产环境非常重要：**swa=0.2 提供可预测的稳定性能，不依赖预热**。

## 总结

| 维度 | swa=0.1 | swa=0.2 | 结论 |
|------|---------|---------|------|
| C10 吞吐 | 高（R3: 7726） | 低（R3: 6107） | swa=0.1 胜 26% |
| C30 吞吐 | 高（R3: 22351） | 低（R3: 10683） | swa=0.1 胜 109% |
| C60 稳定性 | R2 即 OOM | 三轮全部成功 | **swa=0.2 胜** |
| 预热依赖 | 严重（R1→R3 翻倍） | 几乎无 | swa=0.2 胜 |
| TPOT（decode 延迟） | 低 | 高 17-29% | swa=0.1 胜 |
| 性能可预测性 | 差（波动大） | 好（波动小） | swa=0.2 胜 |

## 建议

1. **生产环境推荐 swa=0.2**：稳定性是第一优先级。swa=0.1 的 C60 OOM 和对预热的严重依赖使其不适合生产。swa=0.2 虽然绝对吞吐较低，但三轮稳定、无 OOM 风险
2. **低并发场景可考虑 swa=0.1**：如果业务确定并发不超过 30，swa=0.1 在预热后吞吐远超 swa=0.2（C30 R3: 22351 vs 10683）。但需注意预热期性能差（C30 R1 仅 11932），且无法应对突发高并发
3. **swa=0.2 的吞吐损失需权衡**：C10/C30 吞吐分别损失 21% 和 52%，换来的是 C60 完全稳定和性能可预测。如果 60 并发是核心场景，这个权衡是值得的
4. **后续可测试中间值**：swa=0.15 可能在吞吐和稳定性间取得更好平衡，值得测试
